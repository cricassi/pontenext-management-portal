# PonteNext Management Portal

## Scopo

Portale web gestionale per l'amministrazione dell'associazione Ponte Next.

La piattaforma serve per gestire in modo centralizzato:

- soci e iscritti
- ruoli associativi
- iscrizioni e rinnovi
- quote associative flessibili
- sponsor
- contributi sponsor
- eventi
- comunicazioni email
- report esportabili

## Tipologia prodotto

Piattaforma web responsive accessibile da browser.

Non è un'app mobile nativa.

## Utenti

- Super Admin
- Admin

I soci non accedono al sistema.

## Stack tecnologico

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase Auth
- Supabase PostgreSQL
- Vercel
- GitHub
